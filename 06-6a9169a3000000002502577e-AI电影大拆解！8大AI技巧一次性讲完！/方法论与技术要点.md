# 06 方法论与技术要点（已按提示词对比修正）

## 口播技巧

1. 脸和身体拆开，状态（正常/受伤/换装）也拆开  
2. 声音 = 参考音频 + 固定说明书 + 测试到稳  
3. 场景用 3/4、地标、文字地图、1 秒全景站位  
4. 提示词具象化：比较和物理过程，不用程度副词  

标题写“8 大技巧”，口播实际展开以上几组；其余被他归到“我们星球里已经讲过、只是没人组合着用”。

## 看完提示词后补上的要点

1. **“不是因为提示词”要改读成“不是因为空提示词”。**  
   Higgsfield 的文本其实很多，但都是资产约束和物理描述。长片稳定靠的是可复用资产，句子只负责激活这些资产。

2. **一张图信息越多，全景时脸越容易丢。**  
   好资产会主动删掉图上的头。这和 08 批评 16:9 四视图人脸太小，是同一条物理限制。

3. **声音说明书和 02 的声音公式是一套东西的电影版。**  
   02 解决单句机器味，06 解决整部电影里同一个人不能换嘴。都要写口音、语速、习惯，而不是“男声”。

4. **具象化是反 8K 的另一面。**  
   05 删画质词，06 把“真实”改写成重力。都是把评价词换成世界里的可观察事件。

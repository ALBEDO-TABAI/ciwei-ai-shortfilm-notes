# 11 提示词提取与好坏对比

同一张脸反复丢进 GPT Image 2.0（编辑/蒙版）。界面输入常被拼音联想和字幕挡住，下面按口播 + 能读到的结构校正。口播是“病弱公子”；画面里被识别成“病娇工资”，按口播和注释校正。

## 坏例子

### 1. 只写身份标签

口播反对的写法就是：`少年将军` / `贵妃` / `很漂亮`。五官已经锁在参考脸上了，再贴职业名不会自动长出盔甲硬挺或残妆。

### 2. 男角色往脸上堆妆

将军、刺客、侠客如果妆面太重，会失去质感。气场不在粉底，在发型和配饰。

### 3. 女角色只写漂亮，或贵妃永远盛装

落魄千金“只是漂亮”没有阶层和故事。贵妃不写“刚经历了什么”，宫宴和失宠会生成成同一套完整妆。

## 好例子

### A. 少年将军（同一张脸）

能读到的结构：

> 帮我按照这张脸生成一个少年将军，要有杀气，妆造干净利落，头发微微竖起，服装要有硬挺感

锁的是：同一张脸、杀气、利落、束发/竖起、衣服硬挺。没有写“8K 英俊”。

### B. 病弱公子（同一张脸）

> 帮我按照这张脸生成一个病弱公子妆造，要干净克制，发型披下来，服装颜色可以淡一点，让人物看起来有一种清冷

对照少年将军：同脸，发松、色淡、清冷疏离。男性合同写在服装和头发上。

### C. 宫廷贵妃

> 帮我按照这张脸生成一张宫廷贵妃的画面，妆面不能太素，眉要精致，发髻要规整

女角色把合同写到妆面和发饰：不能太素、眉精致、髻规整——“被规矩养出来的贵气”。

### D. 落魄千金

画面切换到素颜参考脸。口播合同：不能只是漂亮，妆可以有一点残次。具体残在哪，要写进状态，而不是写“可怜”。

### E. 状态向妆造板（他让观众截图的那张）

标题能读到：`进阶·状态向妆造提示词大全`。OCR 还原的格子包括：

| 状态 | 妆造方向（板上能读到的要点） |
| --- | --- |
| 刚赴宫宴 | 妆容完整、发饰规整 |
| 刚失宠 | 妆面变淡、发饰减少 |
| 刚从战场归来 | 发丝凌乱、盔甲残损 |
| 刚受伤 | 血痕伤口、衣服破损 |
| 刚逃婚 | 残妆凌乱 |
| 刚被流放 | 旧衣破损、素色衣袍 |
| 刚完成任务 / 刚被册封 | 轻装劲服 / 妆容明亮 |

口播收束：身份决定方向，状态决定细节。刚参加完宫宴可以妆面完整；刚失宠就不能太满，衣服颜色更沉。

## 不要当好例子的帧

- 片头误切进来的“古风夜街步态”长文：是别的教程残帧，不是本期妆造合同
- 只写“声明：视频内素材为 AI 生成”的空网格

## 好坏差在哪

| 维度 | 坏 | 好 |
| --- | --- | --- |
| 男角色 | 往脸上加妆，或只写“将军” | 同一张脸 + 发型束/松 + 衣服硬/淡 |
| 女角色 | 只写漂亮、贵气 | 妆面疏密、眉眼、发髻、残次 |
| 时间 | 身份一次定终身 | 写她刚经历了什么 |
| 参考 | 换脸换五官 | 五官锁死，只改妆造状态 |

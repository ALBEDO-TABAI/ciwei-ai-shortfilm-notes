# 刺猬星球 AI 短片教程笔记

从刺猬星球 superi 的 8 条小红书教程整理出的文字稿、提示词好坏对照、方法论，以及关键提示词截图。

本仓库**不含原视频**。原片请走各组目录里记录的小红书分享链接。

每组常见文件：

- `文字稿.md`：校正后的口播稿
- `提示词提取.md`：视频里出现的好/坏提示词
- `方法论与技术要点.md`：对照截图后修正过的方法
- `prompt_screenshots/`：留下的关键提示词帧
- `frames/`：按 1.5 秒抽的全部帧，便于回看
- `transcript.srt`：语音转写字幕

## 八组

| 组 | 标题 | 核心问题 |
| --- | --- | --- |
| 01 | 用 Codex 精准控制 AI 运镜 | 复杂一镜到底不要手写，用粗模 Previs |
| 02 | 去掉 AI 配音的机器味 | 声音公式，不要只写身份和情绪词 |
| 03 | 三步去掉视频 AI 味 | 底图模型 + 运动验片 + 统一光照 |
| 04 | 反向表演 | 内心≠表面；细时间轴别写成肌肉说明书 |
| 05 | 提示词过期了 | 删 8K，改写拍摄方式和四段式结构 |
| 06 | Higgsfield 长片拆解 | 脸身分离、声音说明书、3/4 空间、具象物理 |
| 07 | Seedance 活人感 | 编号锁特征、iPhone 生活场景、给手找事 |
| 08 | 短剧资产库 | 四视图要脸大、九宫格场景、色板三层、资产别少别花 |

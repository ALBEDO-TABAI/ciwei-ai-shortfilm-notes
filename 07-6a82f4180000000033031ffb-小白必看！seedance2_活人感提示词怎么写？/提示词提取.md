# 07 提示词提取与好坏对比

## 坏例子

- 只上传一张四视图，提示词里不锁特征  
- 用 AI 场景图或摄影集当环境  
- 人物空手站着，全靠“自然一点”  
- 再写 8K、细腻、细节拉满  

## 好例子

### 人物编号 + 锁定特征（关键帧）

界面标签：`人物A1`，女主严格参考某张图。

> 23 岁年轻东方女性，性格开朗自然，喜欢摄影。固定为红棕色长卷发、中分、……玛瑙色……鞋，挎带黑色手提包。  
> 面孔、五官、年龄、身材和手提包全程一致，不掉包。  
> 自拍视频中偶尔对镜头微笑，更多时候自然观察湖面、整理头发、拍照、走路。

格式要点：

1. 编号（A1）  
2. 身份一句  
3. 3–5 个不可变特征（发色、中分、包）  
4. 明确“全程一致，不掉包”  
5. 行为菜单，而不是单一摆拍

### 一段话里的时间轴 + 真实场景指图

> 镜头跟随她走向打开的木门，进入【图片5】。必须表现旧木门、纱帘、阳台上晾晒的衣物和墙面的咖啡装饰画。  
> 女主站在门口，用后背接住被风吹动的衣物和阳光。她用美甲手推开纱帘，把晾晒衣物从锁……  
> 【capture 2 | 沿湖散步】

好在：场景是生活空间指图，不是精修摄影；人物手里有门、纱帘、衣服可做。

### 口播规定的成稿顺序

1. 画面质感与拍摄参数  
2. 人物身份 + 编号 + 锁定特征  
3. 场景和道具  
4. 时间轴分镜  

全部塞进一段话，不要拆成互相打架的短指令。

## 好坏差在哪

| 维度 | 坏 | 好 |
| --- | --- | --- |
| 人物 | 只有四视图 | 四视图 + A1 + 3 到 5 个锁死特征 |
| 场景 | AI 场景 / 摄影集 | iPhone 生活实拍 |
| 道具 | 空手 | 门、衣、包，给手找事 |
| 结尾词 | 8K 细腻 | 质感参数 + 时间轴 |

# 07 方法论与技术要点（已按提示词对比修正）

## 口播三块 + 一段话组装

脸（编号和特征）→ 真场景（iPhone 生活）→ 真道具（给手找事）→ 按“质感 / 身份 / 场景道具 / 时间轴”塞进一段话。

## 看完提示词后补上的要点

1. **活人感不是皮肤滤镜，是“这个人一直还是她，并且有事可做”。**  
   好例子同时写了不掉包，和整理头发、推纱帘、拍照。空镜美人最容易死。

2. **参考图是证据，提示词是合同。**  
   四视图只提供长相样本；合同条款是“红棕卷发、中分、黑手提包全程一致”。人物一多，没有合同就会串角。

3. **场景太美会假。**  
   这是 05“别写电影感”在选图上的版本：摄影集光太完美，模型会生成广告，不会生成生活。

4. **一段话组装，是为了避免指令冲突。**  
   和 05“不要把动作拆到互相打架”一致。时间轴可以有，但要嵌在同一条上下文里。

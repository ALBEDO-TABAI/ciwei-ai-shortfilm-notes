# 08 方法论与技术要点（已按提示词对比修正）

## 口播框架

资产三大类：角色、场景、道具，加色板。  
角色内部再拆：脸、装造、表情动作。  
场景用九宫格 + 平面图。  
道具分实体 / 虚拟。  
色板分颜色 / 属性 / 用途。  
坑：太少、太花。

## 看完提示词后补上的要点

1. **资产库是前 7 条能成立的基础设施。**  
   01 的 Codex 运镜、03 的底图、06 的长片、07 的活人感，全都假设你手里已经有“脸够大、场景有布局、道具能指”的资产。本条把这个前提补齐。

2. **16:9 四视图看起来专业，其实是坏资产。**  
   和 06 批评普通三视图一样：信息密度高，但脸的像素不够。资产图要按**模型读取权重**来排版，不要按人类海报审美来排版。

3. **色板的第三层“使用场景”才是提示词接口。**  
   只给 HEX，模型不知道它涂在墙还是皮肤上。好色板等于在预写后半段提示词里的材质句。

4. **“太花”和 05 的 8K、07 的摄影集是同一个错误。**  
   资产阶段就追求氛围，等于把过期风格词固化进参考图，后面怎么写克制都晚了。

5. **虚拟道具被忽略，是动作戏抽卡的隐因。**  
   模型没见过这招长什么样，只能生成“很用力地比划”。这和 01 必须让真假信长得不一样，属于同一类：先让关键差异可见。

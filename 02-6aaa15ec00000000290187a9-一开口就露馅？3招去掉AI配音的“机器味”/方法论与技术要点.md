# 02 方法论与技术要点（已按提示词对比修正）

## 口播三招

1. **音色**：丢掉同质化 skill；不要只写“谁在说话”，要写“怎么说话”。  
2. **语气**：把情绪结果改成过程结构。  
3. **语速**：用标点控制节奏；逗号减速、省略号停顿、感叹号爆发。可选声线克隆。

## 看完提示词后补上的要点

1. **AI 听得懂的是声学结构，不是性格名词。**  
   “冷艳公主开口”看起来像提示词，其实是空标签。好例子每一项都能对应到音高、气声、停顿时长。

2. **公式不是要你写满十个词，而是防止漏掉可控维度。**  
   十要素里，口播最常被省略、也最有效的是：情境压力、呼吸、重音、尾音、环境（门外敲门会改变音量）。

3. **标点是给模型的时间轴，不是语文润色。**  
   “明天……和我一块去玩吧！”里的省略号，在好例子里被翻译成“停顿 0.3 秒”。以后写台词，应能把标点还原成秒。

4. **单镜头多句对白必须时间化。**  
   好截图不是一段散文，而是 `0–1秒 / 1–2.5秒 / 完整台词 / 声音设定` 四层。这和 01 的“五件事必须看清”、04 的“情绪要有先后”是同一套时间思维。

5. **机器味的根因经常在剧本，不在 TTS。**  
   先删模板 skill 和说明书台词，再调声音公式；否则再好的声线也是同一张嘴在念稿。

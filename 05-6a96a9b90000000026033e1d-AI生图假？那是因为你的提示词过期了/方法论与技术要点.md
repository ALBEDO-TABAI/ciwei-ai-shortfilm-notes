# 05 方法论与技术要点（已按提示词对比修正）

## 口播核心

- 提示词过期 = 任务变了，不是单词被拉黑  
- 生图：从“把画面做好”改成“这张照片怎么拍出来的”  
- 生视频：少拆动作过程，多写原因、后果和结构  
- 四段式：内容设定 → 素材分工 → 整体基调 → 分镜  

## 看完提示词后补上的要点

1. **8K 不是中性词，它会把模型往“过度精致”推。**  
   删除线帧证明：同一段站台戏，去掉画质词才进入“拍摄现场”逻辑。

2. **四段式里最容易被忘掉、却最有用的是“素材分工”。**  
   好例子明确写：只参考脸和衣服，不参考姿势、背景、构图。这直接避免“参考图姿势粘死”。

3. **分镜写节拍，不写肌肉。**  
   5.5–8 秒只写“加快步伐离开、镜头留空”，不写每只脚怎么迈。这修正了 04 里那种过细时间表，也修正了“视频提示词越短越好”的误解：短不是美德，**结构完整、过程留白**才是。

4. **真实感词要落到器材和光，而不是风格形容词。**  
   ARRI / Cooke / Portra / 窗口光，是在模拟一张被拍出来的照片；“电影感”是在要求一张被生成出来的海报。
